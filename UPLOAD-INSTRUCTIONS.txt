SIDELINEIQ v0.22.2 — GAME OPENING ROOT-CAUSE FIX

ROOT CAUSE FOUND
- v0.22.0 introduced roster-driven quick selections that call teamById().
- teamById() was referenced in several places but was never actually defined.
- When a game opened, renderGame() built the offense/defense panes.
- offenseMemory() -> rememberedPlayers() called teamById(), causing a ReferenceError.
- The URL/GUID changed correctly, but rendering stopped immediately, which looked like the click did nothing.

FIX
- Added teamById() and gameById() helpers.
- renderGame() now uses the helpers consistently.
- Added explicit missing-game / missing-team handling.
- Added a route-level error screen so future runtime errors are visible instead of looking like a dead click.

BUILD
- v0.22.2
- Migrates from v0.22.1
