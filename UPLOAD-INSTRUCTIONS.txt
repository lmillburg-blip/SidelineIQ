SIDELINEIQ v0.20.4 — SETUP UI REDESIGN

This release specifically fixes the New Team / New Game screens.

ROOT CAUSE
- The setup forms were using the CSS class ".field".
- SidelineIQ also uses ".field" for the actual football field.
- The football field rule forces a large green field-like box, which is why the setup screens looked like giant green MS-DOS panels.

FIX
- Setup inputs now use dedicated ".setup-field" classes.
- No collision with the football field styling.

NEW TEAM
- Fits on one screen.
- No scrolling.
- Compact team-name field.
- Clean primary/secondary color controls.
- Football shown as a compact status chip.
- Branded dark-teal header and light body.

NEW GAME
- Fits on one screen at normal desktop/tablet sizes.
- No scrolling.
- 3-column compact layout.
- Opponent, date, location, opponent color, format, opening kick, kickoff yard all visible at once.
- Small kickoff information callout.
- Cleaner action bar.
