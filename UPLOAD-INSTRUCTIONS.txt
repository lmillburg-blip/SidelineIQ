SIDELINEIQ v0.20.0 — IN-GAME ANALYTICS

IMPORTANT CORRECTION
- The intended version is v0.20.0.
- The previous v0.2.0 package contained the analytics code, but its internal BUILD/DB version values were stale.
- v0.20.0 corrects those internal version values and cache keys.

WHERE IS ANALYTICS?
- Open a live game.
- In the top navigation strip, Analytics is BETWEEN Games and Reset.
- It has a cyan highlight to make it easy to see.

ANALYTICS
- Two side-by-side team columns.
- Total yards.
- Rush yards + attempts.
- Pass yards + completions/attempts.
- Turnovers.
- QB, RB/rushing, WR/receiving, and defense tables.
- Click a player number to open individual game statistics.

DEPLOYMENT
- Upload ALL files/folders to the repository root.
- After GitHub Pages finishes deploying, force refresh.
- Visible build badge should read v0.20.0.
