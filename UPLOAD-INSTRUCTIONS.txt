SIDELINEIQ v0.15

Built directly on the approved v0.14 brand assets. No new branding images were generated.

CHANGES IN v0.15

FIELD / POSSESSION DIRECTION
- Fixed the post-kickoff drive direction.
- Kick travels toward the opponent.
- Return travels back the opposite direction.
- The receiving offense now CONTINUES in the same direction as the return instead of flipping back to the kickoff direction.
- First-down marker, yardage calculation, touchdowns, turnovers, punts, and possession changes now follow the active drive direction.

RECENT PLAYS
- Removed US / OPP.
- Uses the first 3 letters of the actual team name (example: AUB, ROC).
- Each play row is color-coded using a lightened version of that team's primary/secondary color scheme, with the primary color as an accent.

PENALTIES
- Offense / Defense is now a toggle instead of a dropdown.
- New Apply To toggle: Current / Former.
  - Current adds the flag to the play being entered.
  - Former attaches the flag to the immediately previous saved play.
- New Accepted / Declined toggle.
- Multiple penalties can be added to the same current play.
- Multiple penalties can also be attached to the former play.
- Declined penalties are recorded but do not affect enforcement.
- Multiple accepted penalties are enforced together, allowing offsetting/canceling yardage.
- Repeat Down / No Play and Automatic First Down remain available.

DATA
- Uses sidelineiq_v015.
- Migrates from v0.14 first, then earlier local stores.
