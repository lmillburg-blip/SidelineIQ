SIDELINEIQ v0.22.1 — GAME OPENING FIX

FIX
- Reworked the Games list opening logic.
- Game rows now use one delegated click handler instead of attaching a separate click handler to every row.
- Added an explicit Open button to every game row.
- Entire row remains clickable.
- Keyboard Enter/Space also opens the selected row.
- Added openGameById() helper that verifies the game exists before navigating.
- If the app is already on the same game hash, it renders the game directly instead of depending on a hashchange event.

WHY
- This removes reliance on row-specific event bindings that can be lost when the Games panel is re-rendered after using Roster or Analytics tabs.
