SIDELINEIQ v0.15.9 — KICK/PUNT RETURN TOUCHDOWNS

NEW
- Kickoff return workflow now includes Return TD.

KICKOFF RETURN TD
- Mark Return TD during the receiving-team return stage.
- Receiving team is awarded 6 points.
- Recent Plays records RETURN TD.
- Ball/possession transitions to touchdown state.
- App enters the post-touchdown try workflow.
- Return TD and Touchback are mutually exclusive.

PUNT RETURN TD
- Mark Return TD in the punt workflow.
- Receiving team is awarded 6 points.
- Recent Plays records RETURN TD.
- App enters the post-touchdown try workflow.
