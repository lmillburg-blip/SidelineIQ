# SidelineIQ PWA v0.12

Static PWA prototype for GitHub Pages.

## GitHub Pages
Upload the contents of this folder to the root of the `SidelineIQ` repository, then go to **Settings → Pages** and choose **Deploy from a branch → main → /(root)**.

## Data
This prototype stores teams, games, and plays in the browser's local storage on the current device. It does not upload game data to GitHub.
