SIDELINEIQ v0.42.4

This is a corrective build for changes that were not visibly landing in v0.42.3.

ROOT CAUSE / FIXES
- Mobile scoring layout is assembled by JavaScript and uses inline !important geometry.
  v0.42.3 tried to resize several controls primarily in CSS, so legacy rules could still win.
- v0.42.4 applies icon dimensions directly in composeMobileGameLayout():
  offense 38x38, defense 34x34, with smaller artwork inside.
- Center field widened from 88px to 112px and increased to 535px tall.
- Analytics styling no longer depends on CSS :has(). showModal() now assigns explicit
  analytics-shell / player-stat-shell classes, so iPhone Safari receives the intended design.
- Corrected malformed historical analytics selectors left by an older CSS patch.
- Next Play penalty support from v0.42.3 is preserved, including PAT/2PT and cross-period enforcement.
- TFL remains derived from negative yardage; Hurry/Missed remain removed.

Existing v0.42.3 data migrates forward.
