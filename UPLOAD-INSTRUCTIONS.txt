SIDELINEIQ v0.41.2 — MOBILE COLLAPSE HOTFIX

Root cause:
v0.41.1 installed mobile pane collapse handlers inside composeMobileGameLayout(),
but renderGame() then called bindGame(). bindGame() also assigns pane-title click
handlers, so it overwrote the mobile collapse handlers before the user could tap them.

Fix:
- compose mobile DOM first
- bind normal game controls second
- bind mobile collapse handlers LAST
- Penalty starts collapsed
- Offense, Defense, and Special Teams start open
- tapping any pane title toggles its body and +/- indicator
- keyboard Enter/Space also toggles
- retains v0.41.1 defense no-horizontal-scroll layout
- migrates v0.41.1 data
