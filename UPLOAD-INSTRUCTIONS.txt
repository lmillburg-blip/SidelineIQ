SIDELINEIQ v0.20.2 — ALL PLAYS / HALFTIME CORRECTIONS

NEW: VIEW ALL
- Recent Plays now has a real View All button.
- Opens a full game-log window with every recorded play.
- Search by play text, player number, or defensive action.
- Filter by period and team.
- Every row has Edit.

RETROACTIVE PLAY EDITING
Designed specifically for halftime cleanup/corrections.

You can edit:
- Period
- Statistical yardage
- Description
- Run ball carrier
- Pass QB
- Pass receiver
- Pass result
- Fumble + who recovered
- Defensive player numbers
- Defensive action:
  Tackle
  Assist
  Sack
  Pressure
  Hurry
  Missed

DEFENSIVE CORRECTIONS
- Add defenders to an old play.
- Add a tackle/assist/sack/etc.
- Remove an incorrect defender.
- Change a defender's action.
- On Pass -> Sack, a Tackle action is still converted to Sack to preserve the existing statistical convention.

IMPORTANT
- Retroactively changing statistical yardage updates the stored end spot used by analytics.
- It does NOT rewind the current live game state. This makes it safe for halftime stat corrections.

EDIT SELECTED
- The existing Edit Selected button in Recent Plays now opens this same richer editor instead of only editing the text description.
