SIDELINEIQ v0.15.3 — GAME RESET / DELETE

New:
- Reset button on live game screen.
- Reset requires confirmation.
- Reset clears scores, plays, penalties, period/down/distance/LOS, and kickoff progress.
- Reset preserves game metadata and returns the game to its original opening kickoff.

- Delete button on live game screen.
- Delete requires confirmation.
- Delete permanently removes the game and all recorded data.
- After deletion, the app returns to that team's Games page.

Deployment verification:
- Build badge should read v0.15.3.
- JS/CSS and service-worker cache versions are bumped.
