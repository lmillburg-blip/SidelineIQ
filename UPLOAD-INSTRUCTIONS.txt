SIDELINEIQ v0.20.3

NEW TEAM / NEW GAME
- Rebuilt as compact, scrollable setup windows with fixed actions.
- Two-column layout on larger screens, one column on smaller screens.

INTERCEPTION
- Pass -> Interception is now two-stage:
  1) Enter interceptor and drag to interception spot, then Lock Interception.
  2) Field flips for return; drag to return end.
- Optional return tacklers and interception return TD.
- Stores interception return data and adds INT / INT return yards / INT TD to defense analytics.

SACK
- Pass -> Sack now requires explicit defensive sack credit.
- Sack is both the QB's offensive result and the defender's defensive statistic.
- Enter one or more sackers with 1.0 or 0.5 credit.

TACKLES / SACKS
- Assist removed from live entry.
- Tackle is 1.0 or 0.5.
- Sack is 1.0 or 0.5.
- Historical Assist records count as 0.5 Tackle in analytics.
- Halftime retro editor now uses the same fractional credit model.
